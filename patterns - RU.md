## Search Insert Position (#35)
- паттерн: Binary Search
- когда: отсортированный массив + поиск элемента/позиции
- суть: mid = (left + right) / 2, сравни nums[mid] с target
  - меньше → left = mid + 1
  - больше → right = mid - 1
  - равно → return mid
- после while → return left (позиция для вставки)
- ошибка: while (left < right) вместо while (left <= right) — пропускал случай left == right
- ошибка: пересчитывал mid в двух местах вместо одного раза в начале цикла
